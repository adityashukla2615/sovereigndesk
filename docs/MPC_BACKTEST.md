## Models

- **Taylor rule**: i* = r* + π + 0.5(π − π*) + 0.5·gap with r* = 1.5% and π* = 4%; it moves a quarter of the way to i* per meeting, in 25 bp steps, at most 50 bp. The output gap is a one-sided HP filter (λ = 1600) on four-quarter real GDP. Deterministic, so its Brier score counts every miss in full.
- **Ordered logit**: cumulative logit on the standardised features with an L2 penalty (λ = 1) on the slopes; at λ = 0 it is statsmodels' `OrderedModel`.
- **XGBoost**: 200 trees of depth 2, learning rate 0.05, row and column subsampling 0.8, L2 leaf penalty 5.
